# Проверка клиента

Область работы — только `client`. Backend проверяется и изменяется отдельно.

## Исправлено

- Стабилизированы зависимости эффекта и обработчик изменения UI-настроек.
- Повторная запись одинаковых настроек не вызывает уведомлений и перерисовок.
- Запись UI-настроек на сервере безопасно пропускается.
- Исходная тема соответствует тёмной теме по умолчанию при недоступном localStorage.
- Добавлены команды `npm run typecheck` и `npm test`.

## Следующие улучшения

- Получать приветствие и подпись профиля из одного источника данных.
- Составить форму ответа из FieldGroup/Field, карточки — из CardHeader,
  CardContent и CardFooter с визуальной проверкой.
- Перед подключением API уточнить DTO: JSON-даты приходят строками,
  а `entities/lessons/types.ts` пока описывает их как Date.

## Проверки

TypeScript, ESLint, производственная сборка Next.js и 11 клиентских тестов проходят.
Для сборки требуется доступ к Google Fonts. Визуальная проверка в браузере не выполнялась.
