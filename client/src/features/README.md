# Учебная платформа

Сохранена текущая структура проекта без введения дополнительных слоёв FSD:

- `app/**/page.tsx` — маршруты и выбор данных для страницы.
- `app/layout.tsx` — единый layout для всех страниц через `AppShell`.
- `features/app-shell` — общий каркас и скрываемый сайдбар; его состояние сохраняется при переходах.
- `features/dashboard` — содержимое кабинета и списка курсов.
- `features/header` — единая шапка с кнопкой меню.
- `features/learning/components` — карточки курсов, поиск и баннер продолжения.
- `features/lesson` — страница урока: видео, автор, вкладки, программа курса и переходы.
- `entities/courses` — типы данных для отображения и статические примеры трёх курсов.
- `shared/components` — бренд, аватар и UI-компоненты shadcn.
- `shared/routes.ts` — адреса страниц и функция построения адреса урока.

Главная — `/`, курсы — `/courses`.
Урок — `/courses/[courseId]/lessons/[lessonId]`, например:
`/courses/ui-ux/lessons/visual-1`.

Серверных запросов, загрузки файлов и записи прогресса нет. Состояние вкладок,
поиска и черновика ответа хранится только в интерфейсе. Видимость общего сайдбара,
раскрытые модули и видимость мобильной программы курса сохраняются в `localStorage`.
Настройки программы хранятся отдельно для каждого курса и восстанавливаются после
переходов и перезагрузки. При недоступном хранилище элементы продолжают работать
в рамках текущей сессии.
Данные в `entities/lessons` оставлены для будущей интеграции с API.

Все страницы наследуют тему из `globals.css`, локальных палитр нет. На компьютере
общий сайдбар сворачивается до иконок, на телефоне открывается в Sheet поверх страницы.
Состояние сайдбара восстанавливается синхронным скриптом в `head` до первой
отрисовки через атрибут `data-sidebar-open` на `html`. CSS использует этот атрибут
до и после гидратации; переключение меню и события хранилища синхронизируют его.
Программа курса расположена справа на широком экране и раскрывается под уроком
на узком. Достижения, недельные цели и статистика пока исключены из интерфейса.

Для стандартных элементов интерфейса используем готовые React-компоненты
shadcn в стиле `base-nova`: Sidebar, Button, Dialog, Sheet, Tabs, Accordion,
Collapsible, Avatar, Progress, Toggle, ToggleGroup, Breadcrumb, Card, Empty,
Badge, Label, Kbd, Input и Textarea. Исходники из официального реестра находятся
в `shared/components/ui`; примитивы интерактивных компонентов основаны на Base UI.
Компоненты в `features` составляем из этих элементов. Не создаём собственные
аналоги стандартных контролов и их механики доступности; локально добавляем
оформление, данные приложения и сохранение пользовательских настроек.

`ProfileAvatar` составляет Avatar и AvatarFallback; `ButtonLink` составляет Button
и Next Link. Программа курса использует Accordion для модулей и Collapsible для
мобильного раскрытия. Фильтры поиска используют ToggleGroup, отсутствие результатов
и уроков — Empty, навигационная цепочка — Breadcrumb. Декоративные иллюстрации,
компоновка страниц, фильтрация данных и анимация раскрытия поиска остаются кодом
приложения: они не заменяют стандартные UI-контролы.
